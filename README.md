# Adel Auditor — AI Automation Specialist Portfolio

A personal portfolio website for Adel Auditor, an AI Automation Specialist. The site showcases professional experience, projects, skills, and services in the AI automation space, providing a polished and informative presence for potential clients and collaborators.

## Key Technologies
- TanStack Start (React SSR framework)
- TanStack Router (type-safe routing)
- Tailwind CSS v4 (utility-first styling)
- Content Collections (markdown content)
- Netlify (hosting and deployment)

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

## Sections

1. **Hero** — Introduction and headline statement highlighting Adel's expertise in AI automation.
2. **About** — Background, professional story, and personal mission.
3. **Services** — Overview of AI automation services offered to clients.
4. **Projects** — Featured case studies and portfolio projects demonstrating real-world impact.
5. **Skills** — Technical skills and tools used across AI, automation, and development.
6. **Experience** — Professional work history and career timeline.
7. **Testimonials** — Client feedback and recommendations.
8. **Blog** — Articles and insights on AI automation topics.
9. **Contact** — Contact form and ways to get in touch.
